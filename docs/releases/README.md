## Правило новых версий

- `MAJOR` — несовместимое изменение продукта или API.
- `MINOR` — новый пользовательский функционал без нарушения обратной совместимости.
- `PATCH` — исправления и небольшие улучшения.

Новая запись всегда добавляется первой строкой таблицы. Для GitHub Release используются тот же номер версии, краткое описание и дата публикации.
