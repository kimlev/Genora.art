# Codex project rules

- Before every task, check the current GitNexus graphs/index and update them if stale; only then begin work.
- After frontend or backend changes, run the relevant tests, commit, push, and use the existing project deploy workflow when applicable.
- After changes, rebuild/update GitNexus and verify the index matches the latest commit.
- Keep reports maximally brief and always include the commit hash/number; state tests, push, deployment status/link, production status only when verifiable, and GitNexus status.
